# Contribuer à JSG Guitar

Merci de votre intérêt ! Corrections de bugs, nouvelles pédales, traductions, idées : tout est bienvenu.

## Signaler un problème

Ouvrez une **Issue** en indiquant :
- votre version de Windows et votre carte son ;
- ce que vous avez fait, ce qui s'est passé, ce que vous attendiez ;
- le contenu de `%LOCALAPPDATA%\JSG Guitar\journal.txt` si le son ne démarre pas.

## Proposer une modification

1. Faites un *fork* du dépôt et créez une branche.
2. Gardez le style du code existant (commentaires en français, C++20).
3. Vérifiez que le programme compile (`sources\build.bat`) et que le son fonctionne.
4. Ouvrez une *Pull Request* qui explique ce que fait la modification.

Ne proposez pas de code copié d'un projet dont la licence n'est pas compatible avec la GPL v3
(en particulier, **aucun code de JUCE**).

## Droits sur les contributions

En proposant une contribution, vous acceptez :

- qu'elle soit publiée sous la licence **GPL v3 ou ultérieure** du projet ;
- et vous accordez à **Jérôme Soler** le droit, non exclusif et gratuit, de l'utiliser, de la modifier
  et de la distribuer sous d'autres licences, y compris dans d'autres versions de JSG Guitar.

Vous restez l'auteur de votre contribution et vous êtes crédité dans l'historique du dépôt.
Vous confirmez que vous avez le droit de la proposer (c'est votre travail, ou celui d'un tiers
sous licence compatible).

Les images de l'interface ne sont pas modifiables par contribution (voir [LICENCE-CONTENUS.md](LICENCE-CONTENUS.md)).
Ne déposez pas les fichiers MP3 des playbacks dans le dépôt : ils sont distribués à part.
